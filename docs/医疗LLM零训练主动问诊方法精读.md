# 医疗 LLM 零训练主动问诊方法精读

> 范围：不改模型参数（零训练），靠**推理时策略 / prompt / 外部知识图谱**来提升"主动信息获取（主动追问）"能力的方法。
> 精读对象：UoT、MedKGI、SGUR、KG-guided Agentic Framework、MediQ（Abstention）、REFINE（EviMed）、BODHI。
> 整理时间：2026-11-24

---

## 0. 先给结论：零训练路线的本质

所有零训练方法都在回答同一个问题：

> **"不改参数，怎么让模型知道『下一个该问什么、什么时候该停』？"**

而它们的答案高度一致——**用"不确定性 / 信息增益"作为选问信号**。再往下分，只有两种做法：

| 派别 | 选问信号从哪来 | 代表 | 是否需要外部 KG |
|---|---|---|---|
| **有 KG 派**（外部结构化知识） | 用知识图谱建"候选假设集"，算每个候选问题对假设集的**熵减/信息增益**，选减得最多的 | MedKGI、SGUR、KG-guided framework | ✅ 需要 |
| **无 KG 派**（模型内部不确定性） | 用模型自身的**置信度 / 自洽性 / 诊断验证**来触发和引导提问 | UoT、MediQ Abstention、REFINE、BODHI | ❌ 不需要 |

**这个分野极其关键**：它直接对应零训练方法的头号软肋——**KG 依赖**。无 KG 派（尤其 UoT、MediQ、REFINE）不碰 KG，天然避开了这个坑，但代价是"选问信号"来自模型自身、精度更弱。这是后文判断研究空白的主线。

## 2. 逐篇精读

### 2.1 UoT（Uncertainty of Thoughts）—— 零训练信息论选问的源头

**出处**：NeurIPS 2024，NUS 等，arXiv:2402.03271。

**Motivation**：
- CoT、ToT 都是"在**已给全信息**的前提下推理"，不解决"信息根本没给全、得主动去要"的问题。
- 模型默认"立刻给答案"，要么过度自信地瞎猜，要么问无关、过早、过于具体的问题。
- 作者要的是：让模型**显式建模"我不知道什么"**，并用信息论量化"哪个问题最值得问"。

**方法（三组件，全部推理时执行，不改参数）**：

1. **候选问题生成 + 多步模拟（simulation tree）**：不直接问，先让 LLM 生成多个候选问题，并"想象"每个问题被回答"是/否"之后会怎样，展开成树（Answerer 节点分叉为肯定/否定两条路）。
2. **不确定性奖励（信息增益）**：用香农熵度量当前"可能性空间"的不确定性，问题把空间切成肯定子集/否定子集，信息增益
   `IG = -p_A·log(p_A) - p_N·log(p_N)`；
   再除以一个惩罚项 `1 + λ⁻¹·|p_A - p_N|`，**惩罚"切得太偏"的问题**（鼓励把空间切成 50/50，即"二分搜索"式提问）。
3. **奖励传播（reward propagation）**：不是只看下一步，而是把期望奖励沿整棵模拟树传播，选**期望长期信息增益最大**的问题。

**关键数字**：跨多个模型（Llama-3-70B / GPT-4 / Claude-3-Opus）平均**成功率 +38.1%**；DX 医学诊断任务 GPT-4 达 97.0% 且减少提问轮数；20 Questions "Things" 上 37.5%（GPT-4 裸跑仅 16.5%）。

**批判**：
- 代价是**推理时算力**：要为每个候选问题模拟一棵树（本质是 test-time compute），延迟高。
- 假设是"可二值化的问题"，对开放式、多值回答的医学问诊不完全适用。
- 但它是**零训练 + 无 KG** 这条路线的正统源头，MedKGI/SGUR 都直接站在它肩膀上。

### 2.2 MedKGI —— KG 接地 + 信息增益 + 结构化状态

**出处**：arXiv:2512.24181。

**Motivation（三个明确的失败模式，这是本文最清晰的地方）**：
1. **幻觉**：模型优先输出"看似合理"而非"已被验证"的医学关联。
2. **低效提问**：问重复、非判别性的问题——因为它没有显式框架去决定"下一个该问什么"。
3. **上下文丢失/过载**：多轮对话里早期确认的证据被稀释，结论前后矛盾。

作者的根本论点：**鉴别诊断是"迭代、假设驱动的系统性证据权衡"，而 LLM 的联想式生成本质与之相反**。三个失败模式分别破坏了这个过程的三个支柱——假设可靠性（幻觉）、信息获取效率（低效提问）、推理一致性（上下文丢失）。

**方法（三组件 + 完整循环）**：

- **组件 1｜KG 接地**：用 PrimeKG（17,080 疾病 + 3,357 症状 + 11,072 疾病-症状边）。三级实体对齐：精确匹配 → Levenshtein 编辑距离（≤3）→ PubMedBERT 语义相似度（≥0.85）。对齐后构建"诊断子图"。
- **组件 2｜信息增益选问（核心）**：
  - 先验：候选疾病与已确认阳性症状的语义相似度均值；
  - 贝叶斯更新：`P(D|S_pos,S_neg) ∝ ∏P(s|D)·P(D)`，**假设症状条件独立**、似然用**均匀分布** `P(s|D)=1/|N(D)|`；
  - 算当前熵 `H(D) = -ΣP(D)logP(D)`；
  - 对每个候选症状算 `IG(s) = H(D) - H(D|s)`，选 **top-k 信息增益最大**的症状去问。
- **组件 3｜OSCE 结构化记录**：JSON 记录"主诉/症状/检查"，每轮增量更新、保留未被矛盾的证据——**用紧凑结构化状态替代不断膨胀的原始对话，防上下文过载**。

**完整每轮循环**：LLM 出候选诊断 → 实体对齐建子图 → 提取正/负症状 → 贝叶斯更新 → IG 选 top-k 症状提问 → 患者/测量 agent 回答 → 更新 OSCE 记录 → 检查终止（轮数 ≤20，或候选集连续不变则停下诊断）。

**关键数字**：Qwen3-8B 在 agent-MedQA **69.81%**（最优基线 61.32%），对话 **9.11 轮**（效率约 +30%）。消融最扎眼：**去掉 KG 掉 25.47pp**（69.81→44.34），**随机选症状掉 38.68pp**，**按节点度数选（流行度偏差）掉 22.64pp**。

**局限（自认）**：① 患者模拟理想化（假设合作、连贯报告）；② **症状条件独立假设** + **均匀似然假设**（把所有疾病-症状边一视同仁，不区分诊断权重）——这是它方法论上最脆的两点。

### 2.3 SGUR（Structure-Grounded Uncertainty Reduction）—— 图对齐的信念选问

**出处**：arXiv:2610.30611。

**Motivation**：
- 核心论点：**可靠的智能体推理不取决于模型多大，而取决于推理过程的结构组织方式**。
- 现有系统"语义流畅但结构无根基"，靠 token 级语言相似性推理，是 Kahneman 说的**启发式替代**（用联想匹配替代在联合证据上的逐步精化）。
- 多轮交互中模型**路径依赖**、过早锁定脆弱假设；**GraphRAG 类方法的图只当检索基底**，拓扑结构不直接定义推理目标；CoT/ToT 仍在模型内部概率空间，无外部结构化约束。

**方法（四步在线循环）**：

1. **四层 KG**：观察(phenotype) → 定位(anatomy) → 候选诊断(disease) → 治疗(drug)；边权 = 出度倒数（**降权通用节点、强调判别性关系**）；节点显著性 `S=log(1+入度+出度)`。
2. **查询图构建 + 候选剪枝**：把每轮观察映射成查询图，用 L₀ 路由（嵌入聚类）+ 路径兼容性筛出候选疾病图。
3. **先验加权部分 FGW 对齐 → 信念分布**：用 **PFGW 距离**（特征差异 + 图结构距离的加权组合）度量查询图和每个候选疾病图的匹配度，softmax 成"信念分布"，熵 = 不确定性。
4. **主动获取（选问）**：在 top-κ 候选图未观察节点里，选**节点显著性加权和最高**的那几个（= 在候选里出现频率高且结构显著的节点）作为下一个问题。

**关键数字**：复杂模式 3 轮后 **Hit@3 92.5%**（最强 GraphRAG 基线 83.1%，+9.4pp）；token 消耗比 GraphRAG **低 5.7×**，延迟低 3.9×；**换小模型（GPT-5.4-nano）保持 99.8%**（92.4%），超过所有用大模型的 baseline——这就是作者强调的"结构-规模替代效应"。

**消融最扎眼**：去掉 L₀ 潜在路由 → Hit@3 暴跌 **-23.6pp**；把 partial transport 换成 full FGW → **-19.2pp**。

**局限（自认）**：① 非临床系统；② 假设知识可组织为层次、观察可映射到标准节点——真实场景有噪声/缺失关系/演化知识；③ 只在 PrimeKG 单一基准验证；④ **L₀ 路由极脆弱**（是最大单点）；⑤ EIG 用了节点显著性的**代理**，非最优；⑥ 表型-解剖边靠 LLM 生成，可能带模型偏差。

### 2.4 KG-guided Agentic Framework（arXiv 2608.19875）—— 澄清歧义后喂给下游 LLM

**Motivation**：
- 患者常发**简短、欠定义的查询**（"头痛该吃什么药？"），字面清楚但**患者特定上下文缺失**（怀孕？抗凝药？肝病？），同一个问题对不同的隐藏前提有完全不同的答案。
- 这是**"患者上下文歧义"**，不同于语言歧义/知识歧义/意图歧义。模型直接答 = 基于无根据的假设。

**方法**：
- 在患者和**不改动的下游 LLM** 之间插入一个中间 agent：KG 建"假设集" → 找出能区分这些假设的**缺失患者上下文变量** → 逐条**算香农熵减**选最该问的 → 针对性追问（是/否）→ 把"原查询 + 澄清结果"拼成 **clarified prompt** 喂给下游 LLM。
- 关键卖点：**下游模型完全不改、不微调**，可插拔。

**关键数字**：诊断检索任务（1,034 条掩码症状）Top-1 从 baseline 的 0.6–11.0% 拉到 **57.7–71.1%**，Recall@5 超 90%；膳食安全分类 MCC 0.781（BASIC 0.716）。反复生成实验显示 clarified prompt 还**降低了模型预测不确定性**。

**批判**：和 MedKGI/SGUR 同源的"KG + 熵减"逻辑，但更偏"澄清问题"而非"完整问诊"；强依赖任务特定 KG（DxSxKG / FoodSafetyKG）的构建。

### 2.5 MediQ（Abstention）—— 最早揭示"裸追问有害"

**出处**：NeurIPS 2024（Shuyue Stella Li 等）。

**Motivation**：
- 交互式诊断里，模型要么过早给答案，要么不会在"该问"时问。
- **反直觉发现（本文最重要贡献）**：直接 prompt 前沿模型"信息不够就追问"，**性能反而下降**——因为它会问无关/重复问题、跨多轮整合信息能力差。→ 说明"追问"不是原生能力，乱加机制会帮倒忙。

**方法（Abstention 三种置信度弃权策略，推理时）**：
1. **Scale**：先让模型给自己 1–5 的置信度打分，低于阈值就追问；
2. **Rationale**：让它先生成"信息是否足够"的理由再决定；
3. **Self-Consistency**：多次采样，若答案不一致则说明不确定，改追问。

**关键数字**：最佳组合比基础交互式 **+22.3%**，比"不交互硬猜" +12.1%；但即使最好，仍比"拿到全信息"的上界**差 10.3%**（多轮整合未解决）。Fact-Select 事实性 89.1%（vs 55.9%）。

**批判**：① 患者系统靠 GPT-4 闭源 API，可能被放水；② 10.3% 的上界差距说明"问"解决了但"整合"没解决；③ 置信度阈值是启发式，需调参。

### 2.6 REFINE（EviMed）—— 诊断验证反推证据缺口

**出处**：ACL 2026 Findings，复旦（龙卓涵、魏忠钰等）。

**Motivation**：
- 传统评估只看"最终诊断对不对"，忽略"证据获取过程"；**强推理 ≠ 强信息获取**——最强的推理模型在信息覆盖率上未必领先，这是交互式场景的真正瓶颈。

**方法**：
- 三角色：模拟患者（主观症状）+ 模拟报告者（客观检查，按"原子证据"粒度）+ 医生 agent。
- **REFINE 策略**：让 agent 先出候选诊断 → 用**诊断验证**回头检查"这个诊断还缺哪些证据" → 针对性追问补齐 → 迭代修正假设。
- 配套指标 **ICR（信息覆盖率）** = 已挖到的必要证据 ÷ 全部必要证据，把"挖得全不全"量化出来。

**关键数字**：跨模型协作有意外增益——**Qwen 铺垫 + GPT 收口**，DiagnosisArena ICR 从 50.8% 拉到 **71.7%**；Derm 上 Qwen→GPT 79.5% 甚至超 GPT-5-mini 单跑 76.7%。说明"谁在前面挖证据、谁在后面收口"高度影响结果。

**批判**：① "诊断验证"本身也要模型去做，可能自证循环；② 原子证据的抽取质量决定 ICR 可信度；③ 依赖 LLM 当模拟患者/报告者。

### 2.7 BODHI —— 纯 prompt 工程（伪追问，需警惕）

**出处**：BMJ Health Care Informatics 2026（MIT）。

**Motivation**：让 LLM 具备"好奇（curiosity）+ 谦逊（humility）"的认识论美德，在信息不足时追问、在不确定时 hedging。

**方法**：两段式 CoT——先内部做"不确定性评估"，再对外回复，并在**那条静态回复里**写 1–2 句澄清问题。**没有多轮信息获取闭环**（问完不会真的拿到答案继续推理）。

**关键数字**：追问率 7.8%→97.3%，hedging 1.7%→21.9%（效应量 d=16.38）。但**临床质量绝对分只有 19.1%**（从 2.5% 极低基线涨上来的）。

**批判（这是最该警惕的一篇）**：
1. **近循环**：prompt 让它"要问澄清问题"，指标就是"数澄清问题"——大效应量证明的是"服从指令"，不是"临床获益"。
2. **基线低到失真**：用 GPT-4.1-mini / GPT-4o-mini 小模型、只在 200 个 HealthBench Hard 子集上测，不能外推到 GPT-5 级。
3. **"追问率"是伪指标**：它和 Hx2Dx 的结论（诊断失败是"问得不对"不是"问得少"）直接矛盾——只优化"问没问"，没优化"问得对不对"。

## 4. 批判性总结 + 对零训练研究者的启示

**三个共识结论**：

1. **选问信号几乎都是"信息增益/不确定性"**——无论是有 KG（算熵减）还是无 KG（置信度/自洽），本质都是"问最能降低不确定性的那个问题"。这说明方向是对的，但**信号来源**是分水岭。
2. **零训练的天花板已经比较清楚**：硬诊断准确率大体落在 60–70%（MedKGI 69.81%），SGUR 的 92.5% 是 Hit@3 且限定在 PrimeKG 单基准，不能直接外推。**零训练提升了"问得省、问得准"，但没有单独解决"问完之后的推理"**。
3. **KG 依赖是零训练路线的头号系统风险**：MedKGI 去 KG 掉 25.47pp，SGUR 去路由掉 23.6pp——这些方法的高度都建立在"有一个高质量 KG"上，KG 覆盖不到的领域直接失效。

**四个可切入的空白点（研究机会）**：

1. **去 KG 化的选问信号**（最值得做）：现有无 KG 方法（UoT/MediQ/REFINE）的选问信号比有 KG 派弱，但 UoT 已经证明"纯信息论 + 模拟"可行。把"选问信号"从"外部 KG + 熵"换成"模型内部不确定性估计"（或特征重要性/主动学习式的信息量度量），既零训练、又摆脱 KG——这正是有主动学习背景的研究者最顺手的切入点。
2. **打破"症状条件独立"假设**：MedKGI 自己承认这是软肋，真实症状高度相关。用相关性结构（而非朴素贝叶斯）建模信息增益，是明确的方法改进空间。
3. **"问"与"诊"的整合**：MediQ 的 10.3% 上界差距、Hx2Dx 的 transcript-transfer，都指向同一个未解问题——**多轮证据如何被可靠地累积成诊断**，而不只是"问对问题"。
4. **零训练方法的跨域鲁棒性**：现有方法几乎都在 PrimeKG / MedQA 圈子里自证，换专科、换 KG、换真实患者，性能是否还在，基本没有系统检验。

**一句话**：零训练路线的本质是"用信息论把『问什么』变成可计算问题"，成熟且成本低，但天花板和软肋（KG 依赖、症状独立假设、问诊整合）都很明确——这些恰好是研究者可以差异化突破的地方。
