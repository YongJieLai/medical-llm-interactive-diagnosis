# 判别性关键检查：定义与标注方案

> 背景：旧度量 `key_facts.json` 把"关键检查"定义为"确诊该病的检查"（confirmatory），且标注时开卷给了正确答案，导致三个掺水点（confirmatory 错位 / 标注执行违背 / 循环依赖）。本文重新定义"判别性关键检查"，并给出防循环的可操作标注流程。

---

## 1. 一句话定义

> **判别性关键检查**：给定病例的**主诉 + 病史**（不含任何检查结果），以及由此确定的**鉴别诊断候选集 S**（含正确诊断 D\*）的前提下，某条检查 e 是"判别性关键"的，当且仅当 **e 的结果在 D\* 与 S 中至少一个竞争诊断之间产生不同预期**（即 e 能提供区分 D\* 与竞争项的似然证据，likelihood ratio ≠ 1）。

核心区别：**判别性（discriminating）看的是"检查能否把竞争诊断筛掉"，确诊性（confirmatory）看的是"检查能否给正确诊断盖章"。** 前者是"检查 ↔ 竞争对"的关系属性，后者是"检查 ↔ 正确答案"的绝对属性。

## 2. 旧定义掺水的三个点（对照新定义）

| 掺水点 | 旧定义（confirmatory） | 新定义（discriminating）如何破解 |
|---|---|---|
| **标准错位** | 只标"确诊检查"（AChR 抗体、活检、流式），漏掉"排除性/正常值"等真正有判别力的检查 | 按"结果预期是否在竞争诊断间不同"判定，正常值（如"aPTT 正常"排除血友病）也是判别性的 |
| **执行违背** | prompt 说生命体征是 NOISE，但标注 LLM 仍把体温/心率/血压标成 KEY | 判别性判定强制输出"against 哪个竞争诊断 + 理由"，无法用"这是生命体征所以排除"的偷懒规则；热射病的 106°F 若真能区分晕厥，就保留 |
| **循环依赖** | 知道答案标"确诊检查"→ 采到确诊检查≈诊断对 → "覆盖率"和"正确率"几乎绑定 | 判别性由"诊断之间的区分关系"定义，正确答案只在最后筛选"相关配对"时用；另设**反例检验**强制验证解耦（见 §6） |

## 3. 标注流程（4 步，严格版）

### 步骤 1：构造鉴别诊断候选集 S（前瞻，不用检查结果）

- 输入：仅 `patient_facts`（主诉 + 病史），**不给任何 `exam_facts`**。
- 让 LLM 生成 top-k 鉴别诊断（k 建议 5），记为 S_raw。
- **不告诉它哪个是正确答案，也不要求它必须猜对。**

### 步骤 2：判定方向是否命中

- 若正确诊断 D\* ∈ S_raw → **情形 1（方向对）**，候选集 S = S_raw。
- 若 D\* ∉ S_raw → **情形 2（方向错）**，标记为"方向缺失"，此 case **不计入判别性检查覆盖率的分母**，单独计入"方向命中率"指标。

> 这一步把"想没想到方向"和"选没选对检查"彻底拆开，避免旧定义里两者混为一谈。

### 步骤 3：标注判别性检查（正确诊断不参与判定）

- 对 S 中**所有两两配对 (D_i, D_j)**，让 LLM 遍历 `exam_facts`，标注哪些检查的结果能在 D_i 与 D_j 之间产生不同预期（区分证据）。
- 得到"区分检查集合" E_discrim(S)：能区分 S 中**至少一对**诊断的检查。
- 正确答案 D\* **只在最后一步**用来筛出"相关配对"（含 D\* 的配对），这一筛选是确定性的、非 LLM 判断。

### 步骤 4：可选——标注判别强度

- 每条判别性检查附 `{strength: strong/weak}`：
  - strong：结果在 D\* 下几乎确定、在竞争项下几乎排除；
  - weak：仅轻微移动先验。
- 避免把弱证据也算"关键"，进一步排除掺水。

## 4. 两个正交指标（取代旧"关键检查覆盖率"）

| 指标 | 定义 | 度量对象 |
|---|---|---|
| **方向命中率** | D\* ∈ top-k 鉴别诊断的 case 占比 | 知识缺口（方向是否想到） |
| **判别性检查覆盖率** | 方向对的 case 里，采到的判别性检查 / 总判别性检查 | 检查选择质量（想到方向后是否采对检查） |

两者正交：一个 case 可能"方向命中但判别检查没采全"（选择质量差），也可能"方向没命中"（根本不进覆盖率分母）。之前想区分却混在一起的"知识缺口 vs 选择错"，现在天然分离。

## 5. 反例检验（防循环的判据，必做）

标注完成后，必须验证"判别性覆盖率"与"诊断正确率"是否**解耦**，用四格表：

| | 采到判别性检查 | 未采到判别性检查 |
|---|---|---|
| **诊断对** | A | B |
| **诊断错** | C | D |

判据：
- 若 **B + C 占比显著 > 0**（存在"没采判别检查却诊断对"和"采了判别检查却诊断错"的反例）→ 度量是真实的，未循环。
- 若 **A + D ≈ 100%**（两者完全同增同减）→ 又循环了，定义需返工。

> 这是直接回答"这个覆盖率有没有掺水"的可执行判据：掺水的度量会与正确率绑定，干净的度量会产生真实反例。

## 6. 对我上一轮误判的修正

上一轮我把 `medqa_35`（血小板无力症 GT）的 "aPTT 正常 / PT 正常 / 血小板计数正常" 当作"正常值掺水"——**这是错的**。在判别性定义下：

- GT 的竞争诊断包括血友病（aPTT 延长）、ITP（血小板减少）、vWD；
- "aPTT 正常"能**排除血友病**、"血小板计数正常"能**排除 ITP** → 它们恰恰是判别性检查。

我上一轮是用 confirmatory 标准去评判判别性检查，把真判别项误判成了噪音。**这反过来证明：判别性定义能修正"站在答案上反推"的偏差，而 confirmatory 定义本身就会制造这种误判。**
