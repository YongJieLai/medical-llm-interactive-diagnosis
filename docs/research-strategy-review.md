# 研究战略复盘与方向规划（供后续 agent 参考）

> 本文档目的：把「交互式医疗诊断 agent 失效分析与零训练插件」这条研究线的**现状、硬结论、
> 他人相关工作、卡点与方向候选**一次性交代清楚。写给你（后续接手/辅助规划的 agent），
> 让你在此基础上思考：**① 从什么角度做；② 怎么做得能得到社区认可。**
>
> 数据口径（除非另标）：EID-Benchmark（AgentClinic-MedQA），qwen-plus，200 例 / 16 turns，
> `deterministic_judge` 判分，显著性用 McNemar（准确率）/ Mann-Whitney U（覆盖率）。
> 所有历史 30 例数字已作废（见 §2）。

---

## 0. 执行摘要（30 秒看懂）

我们做的是**「LLM 交互式（对话式）医疗诊断」的失效分析与方法改进**，目标是找到一个零训练、
可插拔的机制，让诊断 agent 在"边问诊边诊断"的场景下少犯错。

**当前最硬、最干净的三条结论：**

1. **静态→交互存在巨大且真实的准确率落差**（cot 85.5% → 交互式 49–60%，~30pp），
   这是"证据采集"瓶颈，与 CRAFT-MD（82%→26%）、ClinDiag-GPT（57–61%→29–40%）独立印证。
2. **200 例下所有交互方法之间的准确率差异全部不显著**（McNemar p≥0.15）——
   我们曾以为的"+16.7pp"是 30 例噪声。**"准确率"这个指标在这个规模下分辨不出方法好坏。**
3. **「关键证据覆盖率」是唯一强且一致的信号**：正确组 vs 错误组差 +9~18pp，
   11/11 交互模式 Mann-Whitney U p<0.01。→ **失败根因 = "关键证据没采到"，不是"采到了读错"。**

**由此推出的核心战略判断**：这条线的贡献不能押在"我们插件提升准确率"上（已被 200 例证伪），
必须转向 **① 把「关键证据覆盖率」做成一个更早、更强的评测信号（测量贡献）+ ② 证明现有
"信息增益选问题"方法在开放式诊断下失效（复现/反驳贡献）**，方法改进（关键证据引导采集）作为
第三个、风险最高但天花板最高的方向。

## 2. 硬结论清单（可复现、统计显著、可写进论文）

### 2.1 准确率（deterministic_judge，200 例）

| 方法 | 类别 | 准确率 |
|---|---|---|
| cot（静态上界） | 上游原样 | **85.5%** |
| sc | 上游原样 | 59.0% |
| roleplay | 上游原样 | 49.0% |
| react（ReAct） | 上游原样 | 52.5–53.0% |
| refine（论文 REFINE） | 上游原样 | 55.0% |
| refine_cv 系列（refine + CEV-GR） | 上游+我们插件 | 57.5–58.5% |
| MedClarify / MEDIQ / UoT | 外部移植 | 26.0 / 44.0 / 26.0% |

> 方法间差异 McNemar 全不显著（p≥0.15）。**唯一显著且大的效应 = 静态 85.5% vs 交互 49–60%。**

### 2.2 关键证据覆盖率（唯一强信号）

- 把每个 case 的 `atomic_facts` 用 LLM 拆成「关键证据 vs 噪音」，只统计关键证据覆盖率。
- **正确组显著高于错误组 +9~18pp，11/11 交互模式 p<0.01**；而"整体覆盖率"（含噪音）只差 +2~5pp、无信号。
- 结论：**诊断失败 = 关键证据没采到（采集关），不是采到读错（决策关）。**
- 检查类证据是最关键缺口（错题缺失关键证据中检查占 ~68%），与 MedClarify 的
  single-feature masking（实验室 −19.8pp、影像 −16.6pp）**独立交叉印证**。

### 2.3 外部方法复现结论（空起步公平对比）

| 方法 | 声称机制 | 实测准确率 | 关键证据覆盖 | 错题主因 |
|---|---|---|---|---|
| MedClarify（DEIG） | 诊断期望信息增益选问题 | 28.0% | 15.1% | 91.7% 采集不足 |
| MEDIQ（abstention） | 置信度+理由+自洽 | 44.0% | 21.7% | 73.2% 采集不足 |
| UoT（信息增益树） | 期望熵减选问题 | 26.0% | 17.8% | 87.2% 采集不足 |

> 三个零训练方法**没有一个达到它们声称的"关键证据覆盖改善诊断"**：覆盖率仅 12–22%（带我们
> 插件的方法 52–62%），且正确组 vs 错误组差距仅 +1.8~3.2pp（我们 +9~18pp 全显著）——
> **它们采的是区分性噪声，不是确诊证据。** 根因：这些方法的"信息增益"依赖 MCQ 的 ICD 编码 /
> 固定候选池（MedClarify 的 Div 项用 ICD 相似度、INFOGATHERER 用检索文档 DAG），
> 开放式诊断下这些依赖不成立。

### 2.4 CEV-GR 底座敏感性（负结果，但边界清晰）

| 底座 | 结构 | 原样 → +CEV-GR | Δ |
|---|---|---|---|
| roleplay | 采集-诊断解耦 | 49.0% → 57.5% | **+8.5pp** |
| refine | 采集-诊断解耦 | 55.0% → 58.5% | +3.5pp |
| sc | 采集-诊断解耦 | 59.0% → 58.5% | −0.5pp |
| react（ReAct） | 采集-诊断耦合，`[DIAGNOSIS]`=终点 | 53.0% → 46.5%/45.0% | **−6.5~−8pp** |

> CEV-GR 是"采集-诊断解耦底座的可插拔审计层"，不是全范式通用插件。ReAct 掉点根因不是采集
> 变差（覆盖率反而略升 25.3%→26.6%），而是**诊断决策被破坏**（give_up 0%→13.2%）。

## 4. 核心矛盾（决定方向取舍）

```
准确率：所有交互方法差异不显著（p≥0.15）  →  不能用"准确率提升"立论
关键证据覆盖率：正确 vs 错误 +9~18pp 全显著  →  唯一强信号，可作主指标/贡献
```

**推论**：
- 任何"我们方法准确率 > baseline"的 claim，200 例下都站不住，**不能作为论文主贡献**。
- "关键证据覆盖率"是**比准确率更早、更强、更一致**的方法质量信号——这是可以立的贡献点。
- 但要注意：覆盖率是"过程指标"，需要论证它**与真实临床价值的关系**（关键证据覆盖 ↑ →
  诊断正确 ↑，我们已有 p<0.01 的相关性证据，这正是那个论证）。

## 5. 方向候选（从什么角度做）

### 角度 A：测量/评测贡献 —— 把「关键证据覆盖率」立成一个指标 ⭐ 推荐

**命题**：现有交互诊断评测用准确率（Q4Dx 用效率、ClinDiag 用分阶段准确率），但我们在 200 例下
发现**准确率分辨不出方法好坏（全不显著），而关键证据覆盖率能（全显著）**。

**贡献点**：
1. 提出「关键证据覆盖率」：把 case 拆成 atomic_facts，LLM 标注关键 vs 噪音，只统计关键证据。
2. 证明它比准确率**更早、更强、更一致**地反映方法质量（+9~18pp vs 不显著）。
3. 证明"整体覆盖率"被噪音稀释（只 +2~5pp），**必须区分关键/噪音**——这是方法学贡献。
4. 与 Q4Dx 的提问效率指标、ClinDiag 的分阶段指标互补，构成完整评测体系。

**社区认可度**：高。这是"benchmark/metric"类贡献，且回答了一个真实痛点（交互诊断怎么评测）。
风险低（数据已齐），是**最稳的落地**。

### 角度 B：复现与反驳（critical analysis）—— 证明"信息增益选问题"在开放式下失效 ⭐ 推荐

**命题**：MedClarify/MEDIQ/UoT 声称"信息增益选问题能提升诊断"，我们系统复现后发现它们在
**开放式诊断下采的是区分性噪声（关键覆盖 12–22%）、错题 73–92% 死在采集关**。

**贡献点**：
1. 首次把这三个方法**公平移植**到开放式诊断（空起步：首轮只给主诉，病史/检查靠提问）。
2. 揭示它们的"信息增益"依赖 MCQ 的 ICD/固定候选池，开放式下**结构性失效**。
3. 与 ClinDiag-GPT 的静态→动态落差、CRAFT-MD 的发现合并成一条证据链：**"主动问诊"还没被
   真正解决，现有零训练方法采不到关键证据。**

**社区认可度**：高。"reproduce + refute"类论文（尤其揭示"看似有效的方法换个设置就崩"）很有
传播力。风险低（数据已齐）。

### 角度 C：方法贡献 —— CEV-GR（关键证据引导采集）⭐ 天花板最高、风险最高

**命题**：既然失败根因是"关键证据没采到"，就把"关键证据"显式化进问诊引导。三层架构
（见 `literature-review-and-cev-gr-design.md` §5）：
- L1 关键证据缺口识别（维护 DDx + 生成"还缺哪些关键证据"清单，检查目录冷启动兜底）
- L2 DEIG-lite 选问题（熵减 + **KeyHit 关键证据命中分**，替换 MCQ 的 ICD/Con 项）
- L3 覆盖感知终止（关键证据覆盖率达标才 FINISH，替换已证负的 DECISIVENESS 门控）

**关键**：主指标必须用**关键证据覆盖率**（唯一显著效应），准确率作辅。消融：去 L1/L2/L3/KeyHit。

**社区认可度**：中高，但**风险最高**——①还没实现；②即使覆盖率提升，准确率可能仍不显著
（历史教训）；③与 MedClarify/ProMed 的差异化要讲清楚（我们是"关键证据显式化 + 开放式 + 零训练"）。

### 角度 D：负结果 + 适用边界 —— CEV-GR 底座敏感性

**命题**：审计/门控类插件不是通用的，只在"采集-诊断解耦"底座有效，在 ReAct（诊断即终点）上
结构性失效（−6.5~−8pp）。给出适用条件判据。

**社区认可度**：中。诚实负结果有价值，但**单独难成一篇文章**，宜作为 A/B/C 的 robustness/讨论小节。

## 6. 社区认可的判断（怎么做得被认可）

1. **不要押"准确率提升"**。已被 200 例 McNemar 证伪，硬报只会被 reviewer 打回。
2. **把"关键证据覆盖率"做成核心资产**：它有三个可独立发表的贡献点（§5 角度 A），且是
   §5 角度 B/C 的共同地基。先立"测量"，再谈"反驳"，最后才是"方法"。
3. **诚实性是最强的护城河**。我们自我推翻两轮（baseline 事故 + 30 例噪声），这本身是
   research integrity 的正面信号，写进 paper 的 limitations/audit 部分反而是加分项。
4. **与最新顶刊对标**：ClinDiag-GPT（Nat Commun）、MIRA/AMIE（Nature）、Q4Dx（Sci Rep）都在
   说"对话诊断"，我们要明确我们的**增量**——它们是训练派/堆工具/测效率，我们是
   **零训练 + 关键证据显式化 + 开放式 + 测量贡献**。
5. **建议的论文结构（合并角度 A+B，C 作展望，D 作 robustness）**：
   - 贡献 1（测量）：关键证据覆盖率作为交互诊断新指标 + 关键/噪音区分方法学。
   - 贡献 2（反驳）：三个信息增益方法开放式复现失效 + 根因（ICD/候选池依赖）。
   - 贡献 3（方法/展望）：CEV-GR 关键证据引导采集 + 底座适用边界。
   - 主线叙事：**"交互诊断的真正瓶颈是关键证据采集；现有方法采的是区分性噪声；需要把
     关键证据显式化，并用关键证据覆盖率来测。"**

## 7. 给后续 agent 的明确问题（要你思考/决策的）

1. **角度取舍**：A（测量）先发还是 A+B 合并一篇？C（方法）值不值得现在投时间实现，还是等
   A/B 站稳后作为 follow-up？
2. **关键证据覆盖率的定义可移植性**：LLM 标注"关键 vs 噪音"是主观的，如何做到可复现
   （标注协议、多标注者 κ、是否可规则化）？这是 reviewer 一定会问的。
3. **覆盖率 → 临床价值的论证强度**：我们只有"正确 vs 错误组覆盖率差"的相关性证据，如何
   进一步论证"覆盖率是因果性的、可干预的"（例如：人为补全关键证据后准确率是否回升）？
4. **CEV-GR 的 L2 KeyHit 项**：如何把"关键证据缺口"具体化成一个可计算的打分，而不只是
   "再问 LLM 一句"？
5. **跨基准验证**：结论目前只在 EID-Benchmark（AgentClinic-MedQA）。要不要在 CRAFT-MD /
   Q4Dx / ClinDiag-Bench 上复跑，验证"关键证据覆盖率"信号与"信息增益失效"是否跨基准成立？
6. **与 ProMed 的区分**：ProMed 也用 atomic_facts + 信息增益（Shapley），但它是 RL 训练派。
   我们的零训练差异化是否足够清楚、足够有说服力？
