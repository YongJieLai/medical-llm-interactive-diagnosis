# F3 泛化 + P2 RAG 汇总（GLM 三组完成）

> 口径：确定性 rule 判定 + None 按错（P3 已验证 None 经 DeepSeek 兜底翻判率≈0）
> 范围：旧 30 例（id 0–29）为跨模型对比标准集；60 例为完整集

## 一、F3 泛化矩阵（生成端 × 核对端，旧 30 例）

| 生成端 | 核对端 | 配置 | 准确率 |
|---|---|---:|---:|
| qwen-plus | qwen | 同模型 | **73.3%** |
| qwen-plus | deepseek | 跨模型 | **40.0%** ⬇ 33pp |
| qwen-plus | glm | 跨模型 | **50.0%** ⬇ 23pp |
| deepseek | deepseek | 同模型 | **76.7%** |
| deepseek | glm | 跨模型 | **76.7%** ⬇ 0pp |
| glm-4-flash | glm | 同模型 | **46.7%** |

## 二、核心发现：跨模型影响是 pair-specific，生成端能力是主导变量

**原假设（F3）**：「跨模型核对一律更差」。**修正后**：

1. **生成端能力主导**。deepseek 作为生成端，无论核对端是谁都是 76.7%；glm-4-flash 作为生成端，同模型也只有 46.7%。生成端的诊断质量是第一变量。

2. **跨模型影响非对称、pair-specific**：
   - qwen 生成端：换 deepseek 核对 -33pp，换 glm 核对 -23pp（跨模型有害）；
   - deepseek 生成端：换 glm 核对 0pp（跨模型无损）。

3. **机制解读**（呼应 `internal reference trap` / `literal matching bias`）：qwen 产出的诊断/证据表述带"qwen 特有风格"，deepseek 核对端读不懂 → 大量 false rejection（40% 组有 17 个判不出的 None，远超其他组）；而 deepseek 产出的表述更规范，glm/deepseek 都能读懂 → 跨模型无损。

**结论**：不应说"跨模型更差"，而应说"**跨模型核对的影响是 pair-specific 的，且被生成端能力主导**"。这直接支撑文档建议的「能力坐标轴 + 表述距离二维边界」站位。

## 四、对后续实验的含义

1. **P0 能力坐标轴**（文档建议）被本次结果**强烈印证**——必须把"生成端独立诊断能力"从"跨模型"变量里分离出来。
2. **P0 格式剥离对照**优先级上升——qwen→deepseek 的 40% 是否"接口/表述问题"，直接决定 F3 的机制定性。
3. **P2 同模型+打乱表述对照**——本次 deepseek 生成端"跨模型无损"反例，正需要用"表述距离"连续变量来解释。
